# Media provenance

Screenshots in `docs/assets/screenshots/` show the real application running
locally with the included fictional fixture. The name Alex Beispiel, employers,
projects, contact details and listings are synthetic. No private pilot is used.

The silent walkthrough is a captioned montage of screenshots of that same local application. Title
cards and captions are editorial additions, not generated application screens.
There is no live AI call, real job collection, application submission, customer
data, paid voice service or third-party footage in the demonstration.

`docs/assets/media-manifest.json` records the source revision and file hashes.
The private archive of the earlier pilot is not redistributed.
