# What this snapshot contains

The application, regression tests, public setup instructions and synthetic demo
are included. Personal databases, CV uploads, backups, credentials, private
infrastructure IDs, account handoffs and the private media-production archive
are not included. A new repository starts without the private project's history.

Core flows to evaluate: review a profile, compare job and freelance listings,
inspect matching factors, save opportunities, review/edit an application draft,
and export a CV from reviewed facts. The demo's listings are fictional and do
not represent current vacancies.

Live search, paid AI, email, scheduled searches, public signup, billing and
internet deployment are outside this demonstration. Provider adapter code does
not imply permission to republish a provider's listings. No third-party listing
data is bundled.

Known presentation limits: some stored matching explanations originate from
Albanian rule strings; generated fallback drafts and their language metadata
need particular care. The public demo uses a transparently authored, editable
example draft rather than claiming it was generated by live AI.
